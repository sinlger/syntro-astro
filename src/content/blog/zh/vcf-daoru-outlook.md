同事发来一个 `.vcf`，双击打不开，打开后也只显示一个人；把整个文件导进 Outlook，几十条联系人最后只进来一条；换到新版 Outlook，翻遍菜单也找不到「导入 vCard」的入口。这三件事看着无关，其实指向同一个原因：**Outlook 各版本对 VCF 的支持并不一样**。

VCF（vCard）是通讯录交换用的文本格式，导入 Outlook 的思路本身没错，错的是版本与方法不匹配。下面先教你怎么判断手上是哪一个 Outlook，再分别给出步骤；如果你的版本压根不认 VCF，最后那条「先转 CSV」的路线可以直接救场。

## 先确认你的 Outlook 版本

打开 Outlook，先看这几个特征：

- **经典 Outlook（Windows 桌面旧版）**：标题栏写「Outlook (经典)」，功能区像 Word 一样密集，左上角有 `文件` 选项卡，点开能看到 `打开和导出`。这是唯一能直接处理 `.vcf` 的 Windows 版本。
- **新版 Outlook**：开始菜单里叫「Outlook (new)」，界面接近网页，左侧是图标式导航栏，**没有 `文件` 菜单**，设置入口在右上角齿轮。它和经典版是两个独立程序。
- **Outlook 网页版 / Microsoft 365**：地址栏是 `outlook.office.com` 或 `outlook.live.com`，操作全在浏览器里，左下角切到 `People`（人员）。
- **Outlook for Mac**：菜单栏是 `Outlook`、`文件`、`编辑`，导入入口藏在 `文件` 菜单里。

一句话记：经典版能读 VCF，新版和网页版不能，Mac 版介于两者之间。

## 经典 Outlook：直接导入 VCF

经典 Outlook 的导入向导里确实有 vCard 这一项，路径是：

1. 点 `文件` → `打开和导出` → `导入/导出`。
2. 选 `从另一程序或文件导入`，点 `下一步`。
3. 文件类型选 `vCard 文件 (.vcf)`，点 `下一步`。
4. 选中 `.vcf` 文件，目标文件夹选 `联系人`，点 `下一步` → `完成`。

问题出在第 4 步之后：**很多版本的经典 Outlook，一个 `.vcf` 里只导入第一个联系人**。文件里装了 200 个人，导入完只多出 1 个。不同版本行为有差异，有的逐条读取，有的只认第一条，官方文档也没把「多联系人 VCF 的批量处理」讲清楚，所以别去赌它的实现。

如果一定要走这条路，先用文本编辑器把文件拆开：每条联系人都是一个 `BEGIN:VCARD` 到 `END:VCARD` 的块，分别存成单独文件再逐个导入。联系人一多，这比转换还麻烦，所以多数人最后会回到 CSV。等表格整理干净、要重新拼成一个 VCF 时，可以看[合并多个 VCF 文件](/zh/blog/hebing-vcf-wenjian/)。

## 新版 Outlook 和网页版：改用 CSV

新版 Outlook 和网页版都没有 vCard 导入入口，官方给的导入方式只有一种：**CSV 文件**。这不是设置藏得深，是功能没做。

新版 Outlook 的路径：左侧导航栏点 `People` → 功能区点 `导入联系人`（少数版本是 `管理联系人` → `导入联系人`）→ `浏览` 选 CSV → `导入`。

网页版和 Microsoft 365 的路径：导航栏点 `People` → `管理联系人` → `导入联系人` → `浏览` 选 CSV → `导入`。

两者都有一条硬性提示：**CSV 必须是 UTF-8 编码**。编码不对时，导入工具会先列出几条示例联系人让你确认，显示不正常就只能取消、换编码重来。所以真正的准备工作不是「找到入口」，而是「把 VCF 变成编码正确、列名能对上的 CSV」。

用本站工具走完这四步，比在 Outlook 里反复试要快：

1. 在浏览器打开 [VCF 转 Excel 工具](/zh/vCard-to-Excel/)，不用安装任何东西。
2. 一次选中多个 `.vcf` 拖进去。工具会把它们解析后合并成一张表，几份手机备份也能一次处理完。
3. 预览这张表：姓名、电话、邮箱、公司、职位、地址、备注各占一列，重复号码一眼能看出来。
4. 选输出格式。要导进 Outlook 就选 **CSV**（导出时写入 UTF-8 BOM，Excel 和 Outlook 都不会把中文读成问号）；想先核对、清洗，就选 **Excel (.xlsx)**。

转换在浏览器本地完成，文件不会上传，客户名单、员工通讯录都可以放心处理。拿到 CSV 后，按上面新版或网页版的入口导入即可。

## Outlook for Mac

Mac 版对 VCF 的态度最微妙，也最容易被 Windows 的经验误导。官方文档说是：`.vcf` 可以导入，双击邮件附件或本地文件，联系人就会存进 Outlook；但**如果这个 vCard 里有多位联系人，窗口只显示第一个，其余的在后台逐条保存**。文件其实被读完了，只是你看不到全部。

同一份文档还写明：Outlook for Mac 目前**既不支持批量导入多个单独的 vCard 文件，也不支持导入 CSV**。这正好和 Windows 版相反——Windows 新版只认 CSV，Mac 版连 CSV 都不认。

老版本（Outlook 2016/2019 for Mac）的菜单里有 `文件` → `导入` → `联系人或其他项目（从 vCard 文件）`，一次一个文件。数量少就逐个双击；数量多就别硬啃，先用工具转成表格，或拿到 Windows 机器上导入。

## 导入失败时的排查清单

- **重复联系人**：经典版的导入向导会问你「替换、允许创建、不导入重复项」，按需选；新版和网页版没有这个选项，重复项会直接叠上去，所以导入前先在表里查一遍重。
- **字段缺失或错列**：Outlook 的 CSV 导入靠列名匹配，「姓名」「电话」这种中文表头可能整列落空。改成 `First Name`、`Last Name`、`E-mail Address`、`Mobile Phone` 这类英文名，匹配率最高。
- **中文乱码**：几乎都是编码问题。用工具导出的 CSV 自带 BOM；别处来的 CSV 就走 `数据` → `从文本/CSV`，把文件原始格式选成 `65001: Unicode (UTF-8)` 再另存。
- **公司名没进对位置**：Outlook 的「单位」和「部门」是两个字段，只给一列公司名时可能整列丢失。表里同时准备 `Company` 和 `Department` 更保险。
- **分隔符不对**：有些区域的 Excel 默认用分号存 CSV，Outlook 只认逗号，导入结果是一整列。换英文逗号重新导出即可。

## 常见问题

**一个 VCF 里有很多联系人，能一次导入吗？**
看版本。经典 Outlook 通常只导入第一个，需要先拆分；新版和网页版根本不接受 VCF；Mac 版会把所有联系人都存下来，但窗口只显示第一个。想一次处理完，先转成 CSV 最省事。

**转换会上传到服务器吗？**
不会。转换在浏览器本地完成，`.vcf` 不会离开你的设备，断网也能用。

**导入 Outlook 后还能导回 VCF 吗？**
经典版可以：`文件` → `打开和导出` → `导入/导出` → `导出到文件` → `vCard 文件`。新版和网页版只能导出 CSV，需要 `.vcf` 时把表格交给 [Excel 转 VCF 工具](/zh/Excel-to-vCard/)重新生成。

**为什么总是推荐 CSV，而不是直接用 VCF？**
因为四个环境里只有一个真正支持 VCF，而且它对多联系人文件的支持还不稳定。CSV 有列名可以核对，导入前能查重、补字段、改表头，出错也知道是哪一列出问题。VCF 是交换格式，不是整理格式。

## 总结

把 VCF 导入 Outlook 卡住，多数不是操作不对，而是版本不对：经典版认 VCF 却常只吃第一个联系人，新版和网页版只认 CSV，Mac 版两者都不批量支持。跨版本都成立的只有一条——**先把 VCF 转成一张干净的表，再让 Outlook 导入 CSV**。打开 [VCF 转 Excel 工具](/zh/vCard-to-Excel/)，把文件拖进去，导出的 CSV 直接喂给 Outlook 就行。
