Excel/CSV를 VCF로 변환한 후 연락처 이름이 알 수 없는 코드로 변해 있습니까? vCard를 가져올 때 중국어 이름이 물음표나 이상한 기호로 표시되나요? 이는 연락처 변환 과정에서, 특히 중국어 연락처를 다룰 때 매우 빈번하게 발생하는 문제입니다.

이 문제 해결 가이드는 **VCF 인코딩 오류** 문제를 정확하게 짚어내어 원인 분석부터 **CSV-VCF 문자 깨짐 복구** 및 **VCF 파일 인코딩 설정**까지 단계별 해결 방법을 제시하여 중국어 표시 문제를 완전히 해결하도록 도와드립니다.

## 문자 깨짐이 발생하는 이유는 무엇인가요?

먼저 핵심적인 이유를 이해해야 합니다. VCF의 중국어 문자 깨짐은 본질적으로 **"인코딩 불일치"** 문제입니다.

간단히 말해, 원본 Excel/CSV 파일의 인코딩 형식이 변환된 VCF 파일의 인코딩 형식과 일치하지 않아 기기에서 중국어 문자를 올바르게 인식하지 못하는 것입니다. 두 가지 일반적인 시나리오는 다음과 같습니다:
1. Excel/CSV는 기본적으로 **ANSI 인코딩**(Windows 시스템에서 일반적)으로 저장되지만, VCF 파일은 중국어 문자를 올바르게 표시하기 위해 **UTF-8 인코딩**이 필요합니다.
2. 변환 도구가 올바른 인코딩 매개변수를 설정하지 못해 변환 과정에서 중국어 정보가 손실되거나 손상됩니다.

또한, CSV 파일에 **UTF-8 BOM 헤더**(Byte Order Mark)가 없는 경우에도 변환 후 문자 깨짐 현상이 발생하기 쉽습니다.

## 해결 방법 1: 변환 전 사전 처리 (권장)

핵심은 원본 Excel/CSV 파일을 **UTF-8 인코딩**으로 표준화하여 근본적으로 문자 깨짐을 방지하는 것입니다:

1. **Excel 파일 처리**:
   변환할 Excel 시트를 열고 "파일" - "다른 이름으로 저장"을 클릭한 다음, 파일 형식을 "CSV(쉼표로 분리)"로 선택합니다. 그 후 오른쪽 하단의 "도구" - "웹 옵션"을 클릭하고 "인코딩" 탭에서 "UTF-8"을 선택한 뒤 확인을 눌러 저장합니다.

2. **CSV 파일 처리**:
   원본 파일이 이미 CSV 형식인 경우 **메모장**으로 파일을 열고 "파일" - "다른 이름으로 저장"을 클릭합니다. 인코딩 드롭다운 메뉴에서 "UTF-8"을 선택하고 원본 파일에 덮어씌워 저장합니다. 일부 변환 도구에서 인식하지 못하는 상황을 방지하기 위해 BOM 헤더를 포함하는 것이 좋습니다.

3. **스마트 변환 도구 사용**:
   Excel2VCF와 같은 전문 vCard 변환기는 인코딩 감지 기능을 갖추고 있어 원본 파일의 인코딩을 자동으로 식별하고 최적의 변환 인코딩을 매칭합니다. 이를 통해 수동으로 UTF-8을 설정하지 않더라도 문자 깨짐 발생 확률을 낮출 수 있습니다.

## 해결 방법 2: 변환 후 복구

이미 문자 깨진 VCF 파일이 생성되었다면, 재변환 없이 다음 방법으로 복구할 수 있습니다:

1. **메모장 인코딩 수정**:
   깨진 VCF 파일을 메모장으로 열고 "파일" - "다른 이름으로 저장"을 클릭한 뒤 인코딩을 "UTF-8"로 선택합니다. 기존 파일에 덮어씌워 저장한 후 휴대폰이나 연락처 소프트웨어로 다시 가져오기를 시도합니다.

2. **도구를 이용한 2차 변환**:
   전문 변환기를 열고 "VCF to VCF" 기능(제공되는 경우)을 선택하여 깨진 VCF 파일을 업로드합니다. 변환 설정에서 출력 인코딩을 "UTF-8"로 수동 지정한 후 변환하여 새로운 VCF 파일을 내보냅니다.

## 해결 방법 3: 휴대폰으로 가져온 후 중국어 이름이 표시되지 않는 경우

변환된 VCF 파일이 컴퓨터에서는 정상이지만 휴대폰으로 가져온 후에만 깨진다면, 이는 휴대폰의 인코딩 인식 문제입니다:

* **iPhone 사용자**: 휴대폰에서 직접 가져올 때 발생하는 인식 오류를 피하기 위해 컴퓨터의 **iCloud** 또는 **iTunes**를 통해 가져오는 것을 권장합니다.
* **Android 사용자**: 휴대폰의 파일 관리자에서 VCF 파일을 찾아 길게 누른 후 "연결 프로그램" - "연락처"를 선택합니다. 가져올 때 "인코딩 선택" 팝업이 뜨면 "UTF-8"을 선택하십시오.

## 결론

VCF 중국어 문자 깨짐 문제의 핵심 솔루션은 **"UTF-8 인코딩으로의 표준화"**입니다. 변환 전 처리, 변환 도구 설정, 혹은 변환 후 복구 중 어떤 단계를 거치더라도 이 핵심 원칙만 지키면 대부분의 문제를 해결할 수 있습니다.

원본에서부터 문자 깨짐을 방지하기 위해 연락처 변환 시 UTF-8 인코딩을 우선적으로 사용하는 습관을 들이는 것이 좋습니다. 복잡한 문자 깨짐 상황이 발생하면 자동 인코딩 감지 및 복구 기능을 갖춘 전문 vCard 변환기를 선택하는 것이 가장 효율적인 방법입니다.
