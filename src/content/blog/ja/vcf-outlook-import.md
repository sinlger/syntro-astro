`.vcf` を開いても連絡先が1件しか出ない。取り込んでも1件しか増えない。新しいOutlookにはvCardを読み込むメニューがない。**VCFの扱いはバージョンごとに違う**のが原因です。

VCF（vCard）は連絡先の交換形式で、表ではありません。まず自分のOutlookを特定し、その手順に従ってください。VCF非対応でも、後半のCSV経由なら4つすべてで取り込めます。

## まずバージョンを確認する

- **クラシックOutlook（Windows）**: タイトルに「Outlook (クラシック)」、左上に `ファイル`。`.vcf` を直接読めるのはこれだけ。
- **新しいOutlook**: 「Outlook (new)」表示で、**`ファイル` メニューがない**。設定は右上の歯車。
- **Outlook on the web / Microsoft 365**: アドレスは `outlook.office.com` 系。連絡先は `People`。
- **Outlook for Mac**: 上部メニューは `Outlook`、`ファイル`、`編集`。インポートは `ファイル` 内。

## クラシックOutlookでVCFをインポートする

1. `ファイル` → `開く & エクスポート` → `インポート/エクスポート`。
2. `他のプログラムまたはファイルからインポート` → `次へ`。
3. `vCard ファイル (.vcf)` を選ぶ。
4. 保存先に `連絡先` を選んで `完了`。

**複数連絡先の `.vcf` でも、最初の1件しか取り込まないことが多い**です。ビルド差があり、公式も明記していません。

使うならメモ帳で1件ずつ分割。表から1つのVCFを作る手順は[複数のVCFをまとめる](/ja/blog/vcf-shugo/)と同じ。

## 新しいOutlookとWeb版はCSVを使う

この2つにvCardのインポート機能はなく、方法はCSVだけ。新しいOutlookは `People` → `連絡先のインポート`、Web版は `People` → `連絡先の管理` → `連絡先のインポート`。

**CSVはUTF-8が必須**。文字化けがあると先へ進めません。

1. [VCFをExcelに変換するツール](/ja/vCard-to-Excel/)を開く。
2. `.vcf` を複数まとめて選ぶ。1つの表に統合される。
3. プレビューで列を確認する。
4. Outlook用は **CSV**、整理用は **Excel (.xlsx)**。

変換はブラウザ内で完結し、送信されません。

## Outlook for Mac

`.vcf` はダブルクリックでインポートでき、連絡先が保存されます。ただし**表示は1件目だけで、残りも個別に保存**されます。

公式には、Outlook for Macは**複数vCardの一括インポートにもCSVにも未対応**です。旧版には `ファイル` → `インポート` → 「vCardファイルから連絡先」がありました。

## インポートでつまずく原因

- **重複**: クラシックは置き換え・許可・除外を選べるが、新しいOutlookとWeb版は不可。表で削除しておく。
- **列ずれ**: CSVは列名で突き合わせる。`First Name` など英語の見出しが安全。
- **文字化け**: ツールのCSVはBOM付き。他所のCSVは `データ` → `テキストまたはCSVから` でUTF-8を選ぶ。
- **会社名が入らない**: Outlookは会社と部署が別項目。`Company` と `Department` を用意する。
- **1列になる**: Excelがセミコロンで保存すると起きる。カンマで出力し直す。

## よくある質問

**複数連絡先のVCFを一度に取り込めますか？**
クラシックは1件目のみ、新しいOutlookとWeb版はVCF非対応、Mac版は全件保存するが1件しか表示しません。CSVが最短です。

**サーバーに送られますか？**
いいえ。ブラウザ内で処理されます。

**VCFに戻せますか？**
クラシックは `ファイル` → `インポート/エクスポート` → `ファイルへエクスポート` → `vCard ファイル`。Web版は[ExcelからVCF](/ja/Excel-to-vCard/)で作り直します。

**なぜCSV？**
VCFを読めるのは4環境中1つだけで、複数連絡先も不安定です。

## まとめ

原因は操作ではなくバージョン。共通の道は**VCFを表にしてCSVで取り込む**こと。[VCFをExcelに変換するツール](/ja/vCard-to-Excel/)にファイルを入れて、CSVをOutlookへ。
